# BKS West Bengal Website (Staging Reconstruction)

Independent **staging** reconstruction of the public BKS West Bengal experience at [bkswbengal.org](https://www.bkswbengal.org/), plus the new **Our Presence** feature.

This repository does **not** claim recovery of the private original source (`BKS-Bengal/west-bengal-website`). Production DNS/deploy is out of scope unless separately approved.

## Stack

- Next.js App Router + TypeScript
- CSS design tokens matched to the live site
- EN / HI / BN language toggle
- Our Presence: interactive West Bengal district map + district/team panel

## Scripts

```bash
npm install
npm run dev
npm run build
```
